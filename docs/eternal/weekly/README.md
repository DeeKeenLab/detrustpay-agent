# Weekly Updates

Create one file per sprint week from `template.md`. Each update should link:

- the one-minute video
- the week's commits or pull requests
- relevant devnet transaction signatures
- user feedback
- the next week's priority

Recommended tags after each update:

```text

eternal-week-3
eternal-week-4
```
