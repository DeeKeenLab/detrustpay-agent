## Evidence rules

- Count a wallet as external only when it is controlled by a non-team tester.
- Count an integration only when another developer can run it independently.
- Link transaction signatures without exposing wallet secrets.
- Explain failed transactions and the product change they caused.
- Label scripted or team-controlled traffic as automated testing.
